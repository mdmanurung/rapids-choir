# rapids-choir

`rapids-choir` is an experimental single-GPU CHOIR port for unimodal RNA
`AnnData` workflows. The package implements RNA preparation, hierarchy
construction, pruning, records, and provenance.

:::{warning}
The package is pre-alpha software under gated scientific validation. No parity,
performance, release, or publication claim is authorized.
:::

Use the [overview](overview.md) to understand the scope. Follow the
[getting started guide](getting-started.md) for a development run. The
[validation status](validation/index.md) defines the current evidence boundary.
