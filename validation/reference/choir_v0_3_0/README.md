# Frozen CHOIR v0.3.0 source reference

This directory is a validation-only snapshot of the R source and package
metadata from:

- upstream: <https://github.com/corceslab/CHOIR>
- version: `0.3.0`
- commit: `0db5e90ef46cd4f2f3765aa812325c8c768563fa`
- commit date: 2025-01-20

The files are not imported by `rapids_choir` at runtime. They exist so
reference fixtures and source assertions remain executable without following a
moving branch. `SOURCE_MANIFEST.sha256` authenticates every copied file.

The snapshot is redistributed under the upstream MIT license. The original
license is present as `LICENSE.md`; its copyright notice is also retained in
the repository-level `LICENSE` and `NOTICE`.
